External services set their own rules and results. Adult content may be restricted, and no service can guarantee finding every repost.

3. If you find a possible repost

  • Record the webpage address and date you found it.
  • Keep relevant evidence securely, without redistributing intimate images.
  • Check the website's reporting process and request removal where appropriate.
  • If intimate imagery was shared without consent, use the platform's non-consensual intimate imagery reporting option when available.

4. What's coming next

  • Local duplicate-image comparison
  • Perceptual hashes for resized or compressed copies
  • Tools to organize found URLs and report status
  • More privacy controls

These matching and tracking features are planned, not implemented in this version. OpenLens currently provides image preview and external search shortcuts.
